Field note

What I learned from building the Interview Drill Coach MVP

The most important implementation choice was not the model. It was narrowing the workflow, defining structured outputs and enforcing a stopping condition. Local file retrieval made project questions grounded, while persistent scores made later sessions adaptive rather than random.
