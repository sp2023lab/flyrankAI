JavaFX Matrix Solver

A desktop mathematics application separating interface code from matrix operations, expression parsing and result formatting.

The problem

Matrix operations involve numerous input shapes, invalid states and numerical edge cases. Combining the interface and mathematical logic would make the application difficult to test and maintain. The project therefore focused on separating interaction, computation and formatting.

My role

I implemented the JavaFX application, controllers, navigation, reusable matrix-grid and scalar-input controls, mathematical operation services, expression parsing, result formatting and automated tests.

How it works

FXML views define the main screens and dialogs. Controllers translate user actions into validated calls to matrix and expression services. The services calculate inversion, determinants, row reduction and systems of equations. A result formatter converts the output into a clear representation for the JavaFX result view.

Technical decisions

An MVC-style structure keeps JavaFX event handling separate from mathematical operations. Matrix parsing and scalar expression evaluation are their own responsibilities. Validation occurs before expensive operations and exceptions are converted into user-facing errors rather than raw stack traces.

Testing and evaluation

The test suite contains more than 50 JUnit tests covering core matrix operations and edge cases. Tests target determinants, inversion, row reduction, parsing, settings and invalid inputs so that interface changes do not silently alter mathematical behaviour.

Outcome

The application supports inversion, determinants, row reduction, systems-of-equations solving and custom mathematical expressions. Its strongest engineering result is not the number of operations but the separation that makes those operations independently testable.

Limitations and next steps

The desktop interface is functional rather than visually polished, and numerical precision behaviour could be documented more explicitly. Future improvements could add step-by-step explanations, larger-matrix performance tests and accessibility review of keyboard navigation.
