# SP2023Lab Portfolio

A one-page static portfolio for Shyam Popat, built for FlyRank PF-04.

## Files

- `index.html` — semantic structure and portfolio content.
- `styles.css` — responsive styling and layout.
- `script.js` — mobile navigation, scroll state, reveal effects and current year.
- `assets/Shyam-Popat-CV-Public.pdf` — anonymised public CV supplied for the site.
- `assets/favicon.svg` — SP favicon.
- `DNS-Walkthrough.md` — PF-04 DNS explanation.
- `netlify.toml` — Netlify publishing and security headers.

## Run locally

```powershell
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to Netlify

1. Open Netlify Drop.
2. Drag this entire folder into the upload area.
3. Open the generated site.
4. Rename it to `sp2023lab` under Site configuration.
5. Test the public URL in an incognito window.

Preferred URL: `https://sp2023lab.netlify.app`
