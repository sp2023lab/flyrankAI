# Reliable Agentic AI Framework
Final-year project investigating the trade-offs of type-safe validation and multi-agent reflection loops on the reliability and performance of autonomous LLM workflows. The planned architecture uses FastAPI, Pydantic models, structured outputs, guardrails, tool-calling and an evaluation harness. Metrics include schema compliance, execution accuracy, recovery performance, latency and token usage.

# Weather Intelligence Dashboard
Python/FastAPI backend that retrieves weather information through a service and client layer, validates requests, stores records through a repository, exposes health and weather routes, and supports CSV export. The project includes configuration management, tests and Docker support.

# AWS Login Service
Authentication-focused Python service using secure password handling, user models, persistence, rate limiting and tests. The project includes Docker Compose, environment configuration, table creation and seed scripts.

# JavaFX Matrix Application
Desktop Java application for matrix operations and expression evaluation. It separates controllers, navigation, settings, formatting and matrix-operation services, with FXML views, CSS and unit tests.

# LLM Follow-up Question Backend
Backend AI project for generating and evaluating follow-up questions. It includes data preparation, model runtime, training scripts, validation, batch evaluation, structured schemas and TruLens evaluation support.
