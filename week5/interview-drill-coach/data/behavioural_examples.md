# Learning unfamiliar backend technologies
During the Elemental Concept placement, new technologies were learned incrementally through scoped monthly projects. The approach was to understand the architecture, build a small end-to-end path, add tests, then improve structure and reliability.

# Handling feedback
Interview feedback indicated that project explanations were strong while behavioural answers and fundamentals needed improvement. The response was to prioritise repeated interview drills with explicit rubrics and follow-up questions.

# Working under a deadline
The first version of the Reliable Agentic AI Framework implementation was completed quickly to establish an end-to-end baseline. The next priority was to validate the architecture with the supervisor and expand the evaluation design rather than adding features without evidence.
