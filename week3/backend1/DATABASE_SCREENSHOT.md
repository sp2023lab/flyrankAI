# DB Browser Screenshot Step

The assignment specifically asks for a screenshot of `tasks.db` open in DB Browser for SQLite.

1. Run the API once so `tasks.db` is created.
2. Open **DB Browser for SQLite**.
3. Choose **Open Database** and select `tasks.db` from the project root.
4. Open the **Browse Data** tab and select the `tasks` table.
5. Make sure the `id`, `title`, and `done` columns and at least the seeded rows are visible.
6. Take a screenshot and save it as:

```text
docs/database-browser.png
```

7. Replace the placeholder text in the README screenshot section with:

```markdown
![SQLite tasks table](docs/database-browser.png)
```

This is deliberately left as a manual step because the screenshot needs to show the actual database viewer on your machine.
