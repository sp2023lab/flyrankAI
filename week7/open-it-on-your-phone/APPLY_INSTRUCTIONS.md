# Apply the Week 7 mobile-polish files

Repository folder:

`week5/sp2023lab-portfolio-v2`

## 1. Add the new stylesheet

Copy `mobile-polish.css` into:

`week5/sp2023lab-portfolio-v2/mobile-polish.css`

## 2. Replace the JavaScript file

Replace:

`week5/sp2023lab-portfolio-v2/script.js`

with the `script.js` supplied in this package.

The new script automatically loads the correct stylesheet path on both the homepage and the `/projects/` pages, so no HTML files need editing.

## 3. Add the fix log

Copy `WEEK7_FIX_LOG.md` into:

`week5/sp2023lab-portfolio-v2/WEEK7_FIX_LOG.md`

## 4. Commit

Suggested commit message:

`Improve mobile readability and diagram accessibility`

## 5. Redeploy

Drag the updated `sp2023lab-portfolio-v2` folder into the existing Netlify project.

## 6. Verify

Open the live site on the same real phone and complete the checklist in `WEEK7_FIX_LOG.md`.
